# Glow: cómo usar este paquete

## Qué hay dentro

- **PROMPT_CLAUDE_CODE.md:** el mensaje que le pegas a Claude Code.
- **CLAUDE.md** y **docs/especificacion.md:** las instrucciones para Claude Code. No hace falta que los leas.
- **datos/:** tu catálogo aprobado, el cuestionario, las referencias de PubMed, los planes y los enlaces de Stripe.
- **prototipo/glow-prototipo.html:** el prototipo que aprobaste.

## Pasos

1. Descomprime `glow-paquete.zip` en tu carpeta **Documentos**.
2. Abre Claude Code y elige esa carpeta (`Documentos/glow-paquete`) como carpeta de trabajo.
3. Copia el texto de `PROMPT_CLAUDE_CODE.md`, pégalo en Claude Code y envíalo.
4. Cuando Claude Code te dé el enlace y el QR de la Fase 1, pruébala en tu móvil y dile qué cambiar o que pase a la Fase 2.

## Qué te pedirá Claude Code y en qué momento

- **Fase 1:** solo que autorices GitHub si te lo pide.
- **Fase 2:**
  - **Supabase:** crear una cuenta gratis en Supabase. Es el servidor de las cuentas, los pagos y el chat.
  - **Stripe:** crear en tu panel de Stripe una clave restringida y pegarla tú en Supabase.
  - **Compra de prueba:** hacer una compra real y reembolsarla.
- **Fase 4:**
  - **Datos legales:** tus datos fiscales y un email de contacto para las páginas legales.
  - **Revisión:** revisar esos textos con un abogado.

## Cosas pendientes que solo puedes hacer tú (cuando quieras)

- **Amazon Afiliados:** añade la dirección de la app (`https://caty0deoliveira-bit.github.io/glow/`) como sitio web en tus cuentas de España y de EE. UU.
- **YesStyle:** confirma en tu panel que las compras hechas desde la app te aparecen con CATYSKIN1.
- **IVA:** coméntale a tu gestoría que el plan Glow con Caty (15 €) lo cobras tú directamente y declaras su IVA. El de 10 € lo gestiona Stripe.

## Costes

GitHub Pages y Supabase son gratis para el piloto. Stripe cobra sus comisiones por cada venta, más un 3,5 % extra en Glow Esencial por gestionar el IVA.
